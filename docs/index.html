The lie detector
for coding agents.

Scans the git diff after any agent claims "done," runs AST and live-trace checks, and returns PASS, SUSPICIOUS, or LIED — with exact file:line citations.

Outcomes

Three verdicts, zero ambiguity.

Every run produces a machine-readable result you can gate on in CI or surface in your IDE.

PASS

Claim checks out

The diff matches the stated intent, static analysis finds no red flags, and all referenced code paths were executed under the live trace.

SUSPICIOUS

Something looks off

The agent's claim is plausible but not fully verified — unreachable branches, missing test coverage, or a partial diff that doesn't match the description.

LIED

Claim contradicts evidence

Hard evidence the agent hallucinated completion — untouched files it said it changed, dead code paths it claimed to execute, or a diff that contradicts the stated task.

Mechanism

How it works.

Two layers of analysis combine to catch both lazy hallucinations and subtle misrepresentations.

01

Intercept the claim

Captures the agent's natural-language completion message and parses it for file paths, function names, and specific assertions.

02

Diff the repo

Runs git diff to surface exactly what changed. Maps every mentioned symbol to actual line numbers.

03

AST static check

Walks the changed AST to verify structural claims — new classes, renamed functions, added branches — without executing any code.

04

Live trace

Attaches sys.settrace during the test run and records every executed line. Cross-references against the agent's claimed coverage.

Distribution

Ships four ways.

Use it wherever you review agent output — the command line, your editor, your CI pipeline, or any MCP-compatible agent host.

⌘

CLI

One command. Point it at any repo and a claim string. Pipe the JSON output into any shell script or CI job.

$ pip install verdict-cli

MCP Server

Plug into any agent host that speaks the Model Context Protocol. Verdict becomes a tool your agent can call on itself.

verdict --mcp-server --port 3456

VS Code Extension

Inline verdict badges next to your agent's output. Click any LIED citation to jump straight to the offending line.

ext install verdict.vscode-verdict

GitHub Action

Add a verdict/check step to any workflow. Fails the check with exit code 1 on LIED, warning on SUSPICIOUS.

uses: verdict-dev/action@v1
